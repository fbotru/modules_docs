# Generated image sources

All images in this directory were generated with the built-in image generation
workflow. The Modern Heritage styleboard was supplied as a style reference:

`external/picgenerator/pics/football/club/default-styles/modern-heritage/_reference/styleboard.png`

Shared direction: premium European sports Modern Heritage; deep navy and
azzurro, muted antique gold, cold ivory, stadium or arena light and editorial
geometry; no national flag accents, real clubs, sponsors, invented text or
player likenesses.
